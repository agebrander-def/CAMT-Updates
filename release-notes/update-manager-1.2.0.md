# CAMT Update Manager 1.2.0

Introduces the CAMT Module Repository.

- New modules can be discovered without first installing a base version.
- Separate Available, Updates and Installed tabs.
- Search and category filters.
- Install/update with mandatory SHA-256 verification.
- Release notes and descriptions.
- Remove installed external modules via Module Framework 2.0.
- Supports both CAMT.ModuleUpdateCatalog.1 and CAMT.ModuleRepository.1.
- Existing v1.1.1 can update itself to v1.2.0 using the compatibility catalog.
